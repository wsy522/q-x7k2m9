☁ 云同步（GitHub）

把进度存到你自己的 GitHub 私密 Gist 里，电脑和手机打开就是同一份进度。
两台设备填同一个 Token 就行，Gist 会自动找到 / 新建。

只存在本机浏览器里，不会写进导出的进度文件。
Token 怎么弄
  1. 手机 / 电脑浏览器登录 GitHub
  2. 打开 github.com/settings/tokens
  3. Generate new token → 选 classic
  4. Note 随便填（如 刷题同步）
  5. Expiration 选 No expiration（免得到期又要重弄）
  6. Scopes 只勾 gist 一个，其它都不勾
  7. 拉到底点 Generate token，把 ghp_ 开头那串复制过来填上面
